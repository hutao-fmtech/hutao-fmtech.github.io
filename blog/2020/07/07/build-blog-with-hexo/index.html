基于 Hexo + GithubPages 搭建个人博客

发表于 2020-07-07 更新于 2020-07-09 分类于 工具 本文字数： 388 阅读时长 ≈ 1 分钟

最近在准备面试，复习以前的一些知识，在网上查找资料时发现很多使用很多博文都是 GithubPages 上的，而且整个博客界面都非常简单实用。搜索一番发现这些都是通过 Hexo + Next 主题构建的，故决定自己也搭建一个玩玩，一来可以记录自己所学内容、加深印象，二来相较于单纯的写笔记更有乐趣。

基础环境搭建

所有的操作都是基于 macOS CataLina 10.15.5 环境，且已经安装 brew 包管理工具，如果执行过程出现异常，请自行搜索解决。

  1. 安装 nodejs
    brew install node

安装完成后，执行node -v，可发现当前 nodejs 的版本为 14.4.0

v14.4.0

  1. 安装 Hexo
    npm install -g hexo-cli
