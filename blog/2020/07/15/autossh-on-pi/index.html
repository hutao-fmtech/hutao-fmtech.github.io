3. 配置免密登录（云服务端）

其实在第二步中拷贝 ssh key 到云应该就OK了，但在腾讯云主机上发现不行，需要在控制台手动添加ssh key，然后再绑定 key 到相应实例，此过程需要重启。

4. 测试能否通过ssh 免密登陆云主机（树莓派端）

如果能免密登录，则进行后续操作，否则查找原因，直到能正常登录为止。
